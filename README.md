A single original funny line, written deterministically to `/output/entry.txt` by `main.py` (Python standard library only, no network, no randomness — the same line on every run).

## The line

> My Roomba filed a restraining order after I kept moving the furniture.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
